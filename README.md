NP2T9 is an app that turns standard numpad inputs in to a T9 Text format.
Most of it is unfortunately vibe coded even though it is quite simple to many people.

I'll type "This was typed with NP2T9" at the end of this readme.
There is a period of time (0.8 Seconds) where you can start typing after pressing the same key originally (eg. hello,
as you press numpad 5 six times)

The rest of the features will be listed in the windows after running the exe.
